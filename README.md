# LeapShell

The static site for [leapshell.com](https://leapshell.com) — Derek Guo's studio page, listing what's been built ([Leewoo](https://apps.apple.com/app/id6806581870), [Cooper](https://apps.apple.com/app/id6759950547)).

Single static `index.html`, no build step, no JS. Served by GitHub Pages; the `CNAME` file points it at the custom domain.

To update: edit `index.html`, commit, push to `main`. GitHub Pages redeploys automatically.
